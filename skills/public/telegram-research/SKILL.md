# Исследование публичного Telegram через Vox

Ты ведёшь исследование сам: придумываешь слова, формулируешь инструкцию для Jev,
проверяешь отбор глазами, решаешь, когда ответ готов. Скрипты только достают и
считают данные.

## Инструменты

- `vox.py` — единственный доступ к Vox (через прокси с рейт-лимитом):
  `search`, `semantic`, `group`, `download`, `authors`, `rank`.
- `jev.py filter` — оценка сообщений по инструкции и сохранение подходящих.

```bash
V=/mnt/skills/public/telegram-research/scripts
python3 $V/vox.py --help
python3 $V/vox.py search --help
```

Долгие команды (`search` за год, `download`, `jev.py filter`) запускай через
`bash(background=True)` и параллель: прокси сам ограничивает нагрузку на Vox.
Повторный запуск той же команды продолжает с чекпоинта, а не начинает заново.

Прокси сам повторяет сбои Vox и отдаёт только полные ответы. Один вызов Vox
ограничен 50 секундами; если запрос не уложился, команда падает с
`Request exceeded 50 seconds. Reduce the date interval and try again.` Тогда
раздели период на окна (`--since`/`--until`, у каждого окна свой `--out`) —
размер окон выбираешь сам по тому, насколько слово частое.

## Период

`SINCE` — дата начала периода из вопроса пользователя. «За последний год» —
сегодня минус год; если период не назван, бери год. Передавай `--since SINCE`
во все `search` и `download`.

## Рабочая папка

Всё в `/mnt/user-data/workspace/research/` (команды запускай из неё):

- `keywords.json` — реестр слов: `{"keywords": [{"word", "round", "source", "searched"}]}`.
  Ведёшь только ты.
- `vox/search/*.json`, `vox/semantic/*.json` — выдачи Vox.
- `jev/relevant.json` — отобранные сообщения (формат ниже), `jev/relevant.rejected.json` — остальные.
- `vox/ranking.json` — рейтинг групп.
- `vox/groups/{group_id}/messages.json`, `authors.json`, `card.json` — выгрузки групп.
- `groups/group_{alias или id}.json` — результат подагента по группе.

## Пайплайн

1. **Слова и поиск сообщений.** Придумай 10–30 слов и коротких фраз, которыми
   люди реально пишут о теме (не термины из вопроса). Запиши в `keywords.json`.
   Для каждого: `vox.py search "СЛОВО" --since SINCE`. Слова в запросе
   соединяются через И: синонимы — отдельными запросами. Запрос 3–49 символов.
2. **Семантический поиск групп.** 3–5 описаний темы обычным языком:
   `vox.py semantic "вахтовики, работа вахтой на северах"`.
3. **Отбор Jev.** Сформулируй инструкцию-вопрос «да/нет» под задачу пользователя
   и прогони все выдачи:
   `jev.py filter "ИНСТРУКЦИЯ" vox/search/*.json --out jev/relevant.json`.
   Подходящие сообщения сохраняются в `jev/relevant.json` в фиксированном
   формате: `group_id, group_name, group_alias, message_id, message_url, date,
   user_id, user_alias, text, keywords, jev_score`.
4. **Проверка глазами.** Прочитай не больше 100 примеров: принятые и
   отвергнутые, особенно около порога (0.3–0.7). Сверь с тем, что нужно
   пользователю.
5. **Перепрогон.** Если Jev путает (берёт рекламу вместо опыта, теряет нужное) —
   перепиши инструкцию и прогони заново в новый `--out`. Повторяй 3–4, пока
   выборка не станет чистой.
6. **Выбор групп.** `vox.py rank jev/relevant.json vox/semantic/*.json --top 16
   [--exclude УЖЕ_РАЗОБРАННЫЕ]`. Скор: уникальные подходящие сообщения группы +
   её `message_count` (оба нормированы) + 1, если группа нашлась и в поиске
   сообщений, и в семантике. Для каждой группы из топа запусти в фоне
   `vox.py download GROUP_ID --since SINCE` и `vox.py group GROUP_ID`.
7. **Подагенты.** По одному подагенту на каждую выгруженную группу, все
   параллельно (`task` или `batch_task`). Задание — по шаблону из
   [group-agent.md](references/group-agent.md): исходный вопрос, `SINCE`, путь
   к выгрузке, путь результата и текущий список `keywords.json`.
8. **Новый круг.** Собери `new_keywords` из `groups/*.json`, отбрось
   уже искавшиеся, добавь в `keywords.json` со следующим `round` и повтори шаги
   1–7 только для новых слов, исключая уже разобранные группы. Останавливайся,
   когда новых слов нет или новые группы не добавляют фактуры к ответу.

## Итог

Ответь на вопрос пользователя по `groups/*.json` и `jev/relevant.json`.
Каждое утверждение — со ссылками `message_url`. Отдельно: группы
(название, ссылка, о чём), внешние ссылки и контакты, киты. Укажи период,
слова, инструкцию Jev и что не удалось проверить. Сохрани отчёт в
`/mnt/user-data/outputs/` и покажи через `present_files`.
