# Подагент: автор отчёта по вертикали

Задание: исходный вопрос пользователя, твоя вертикаль (`NAME` и вопрос), папка
исследования.

Вся выборка уже прочитана, по ней написаны заметки. Ты пишешь отчёт по своей
вертикали по всем заметкам с её `NAME`.

```bash
V=/mnt/skills/public/telegram-research/scripts
python3 $V/notes.py show NAME                 # заметки вертикали
python3 $V/notes.py show NAME --offset N      # следующая страница
python3 $V/read.py --grep 'фраза из сообщения'   # открыть исходное сообщение целиком
```

Прочитай все заметки вертикали до конца. Ключевые сообщения, на которые
опираются выводы, открой через `read.py` и проверь.

## Отчёт

`verticals/NAME/report.md`:

- `## Название вертикали`, затем ответ на её вопрос. Сначала главный вывод в
  2–3 предложениях, потом разделы по сути вопроса.
- **Выводы о рынке, а не набор случаев.** Цифры считай по всем заметкам:
  диапазон, типичное значение и по скольким сообщениям посчитано. Например:
  «доля модели в 140 объявлениях: обычно 25–35%, медиана 30%, от 15% до 50%».
  Отдельные истории — как иллюстрация, а не как основа вывода.
- Каждое утверждение со ссылкой `message_url` на сообщение-пример.
- Отдельно спорное: где стороны говорят противоположное, где тревожные
  сигналы.
- В конце `### Ограничения`: все оговорки один раз и коротко (реклама не равна
  выплатам, тиражирование, что не проверено). В тексте выше оговорки не
  повторяй.

Не пиши в отчёт журнал работы: смещения, страницы, регулярки, файлы, число
вызовов. Не оставляй в отчёте прежние версии: файл пишется заново целиком.
Контакты людей не переписывай. Верни основному агенту главный вывод в 2–3
предложениях и число заметок, по которым написан отчёт.
