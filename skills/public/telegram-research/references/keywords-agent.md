# Подагент: новые ключевые слова

Задание: исходный вопрос, папка исследования.

Ты только предлагаешь слова: добавляешь их в реестр, поиск запускает основной
агент. Сначала прочитай раздел «Как выбирать слова» в
`/mnt/skills/public/telegram-research/SKILL.md` — это правила, по которым
выбираются слова.

Работай из папки исследования. `messages_filtered.json` и `messages_raw.json`
читай скриптами (`jq`, python): большие файлы целиком в контекст не выводи.

1. `python3 /mnt/skills/public/telegram-research/scripts/vox.py registry` —
   все слова со статусом и отдачей. Разложи их по частям карты рынка и найди
   части, где слов мало или нет.
2. Прочитай сообщения по теме, особенно те, где нет главного слова темы, и
   выпиши, как в них называют предмет, роли, площадки, сервисы, деньги и
   проблемы.
3. Добавь 10–20 новых слов одной командой (статус `todo`):

```bash
python3 /mnt/skills/public/telegram-research/scripts/vox.py add_keywords "СЛОВО" ... --source "keywords-agent"
```

Как читать отдачу в реестре: у слов в `todo` `raw = 0`, потому что их ещё не
искали. `on_topic` считается по последнему прогону Jev и отстаёт, пока Jev не
оценил новые сообщения.

Верни основному агенту список добавленных слов: часть карты рынка и одна строка
обоснования на каждое.
