# Подагент: новые ключевые слова

Задание: исходный вопрос, `SINCE`, папка исследования.

Работай из папки исследования. Читай `messages_filtered.json` скриптами (`jq`,
python): большие файлы целиком в контекст не выводи. Уже известные слова —
`python3 /mnt/skills/public/telegram-research/scripts/vox.py registry`.

Найди в сообщениях по теме слова и короткие фразы, которых ещё нет в реестре и
которыми люди пишут об этой теме: жаргон, сокращения, названия мест, компаний,
должностей, синонимы. Каждое слово должно помогать найти новые сообщения по
теме, а не шум. Запрос — 3–49 символов; слова в одном запросе ищутся через И.

Добавь их одной командой (статус `todo`, основной агент запустит по ним поиск):

```bash
python3 /mnt/skills/public/telegram-research/scripts/vox.py add_keywords "СЛОВО" "ФРАЗА" ... --source "keywords-agent"
```

Верни основному агенту список добавленных слов с одной строкой обоснования на
каждое.
