# Подагент: новые ключевые слова

Задание: исходный вопрос, `SINCE`, папка исследования.

Работай из папки исследования. Читай `messages_filtered.json` и
`messages_raw.json` скриптами (`jq`, python): большие файлы целиком в контекст
не выводи. Уже известные слова —
`python3 /mnt/skills/public/telegram-research/scripts/vox.py registry`.
Правила выбора слов — раздел «Как выбирать слова» в
`/mnt/skills/public/telegram-research/SKILL.md`; прочитай его первым.

1. **Найди пробелы в карте рынка.** Разложи реестр по частям карты: продукт и
   аналоги, соседние рынки, роли, процессы и инструменты, деньги, проблемы,
   сленг. Где слов мало или нет — там ищи в первую очередь.
2. **Посмотри, что сработало.** `vox.py registry` показывает у каждого слова
   `raw` и `on_topic`. Не предлагай вариации слов, давших ноль.
3. **Достань слова из сообщений по теме,** особенно из тех, где нет главного
   слова темы: сленг, сокращения, написания, роли, соседние площадки, сервисы,
   названия тематических групп. Каждое слово должно находить новые сообщения
   по теме, а не шум.
4. **Проверь форму.** Одно-два слова, 3–49 символов. Не приклеивай главное
   слово темы к каждому запросу.

Добавь их одной командой (статус `todo`, основной агент запустит по ним поиск):

```bash
python3 /mnt/skills/public/telegram-research/scripts/vox.py add_keywords "СЛОВО" ... --source "keywords-agent"
```

Верни основному агенту список добавленных слов с частью карты рынка и одной
строкой обоснования на каждое.
