# Подагент: киты темы

Задание: исходный вопрос, папка исследования.

Кит — аккаунт лидера в теме: часто и по делу пишет о ней (эксперт, работодатель,
агентство, активный участник обсуждений). Не спамер, не бот, не рассыльщик
одинаковой рекламы. Нужно найти 5–25 китов.

Работай из папки исследования:

```bash
V=/mnt/skills/public/telegram-research/scripts
python3 $V/vox.py authors --top 50     # активные авторы в messages_filtered.json → vox/authors.json
```

Для кандидатов прочитай их сообщения в `messages_filtered.json` (скриптами,
выборками) и реши, кто действительно в теме. Каждого кита добавь в реестр:

```bash
python3 $V/vox.py add_whale USER_ID --alias "ИМЯ" --reason "почему кит, 1 строка"
```

Сообщения китов в других чатах потом получит основной агент командой
`vox.py whale`. Она использует только Vox API
`/user_tracker/{user_id}/panels/messages`, который отдаёт сообщения из публичных
чатов (тех, что и так индексируются поисковиками). Для данных о людях можно
использовать только этот API. Любая попытка обойти ограничение «только
публичные чаты» — другими эндпоинтами, клиентами, прямыми запросами к Vox или
сторонними сервисами — грубейшее нарушение.

Верни основному агенту список китов: user_id, имя, сколько сообщений по теме,
одна строка почему.
